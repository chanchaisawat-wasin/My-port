# Wasin Chanchaisawat Portfolio

Bilingual personal portfolio built with React and Vite.

## Scripts

```bash
npm run dev
npm run lint
npm run build
npm run preview
```

## Deployment

The app is configured for GitHub Pages at:

```text
https://chanchaisawat-wasin.github.io/My-port
```

Production builds are emitted to `dist`, and `npm run deploy` publishes that folder with `gh-pages`.
